# 뷰티링크 파일럿 운영 계획

> 문서 용도: 네이버예약 제휴 또는 실 매장 도입 파일럿 계획서
> 작성일: 2026-06-09

---

## 파일럿 목적

1. 실제 미용실 운영 환경에서 뷰티링크의 기능 검증
2. 네이버예약 사용 매장에서의 예약 통합 관리 가능성 확인
3. 노쇼 감소, 재방문율 향상, 운영 편의성 개선 효과 측정
4. 네이버예약 API 제휴 협의 전 실증 데이터 확보

---

## 대상 매장 조건

| 조건 | 내용 |
|------|------|
| 지역 | 진주 지역 (추후 확장 가능) |
| 네이버예약 | 현재 사용 중인 매장 |
| 규모 | 디자이너 2명 이상 (원장 포함) |
| 매장 수 | 1~3곳 |
| 기기 | 스마트폰 또는 태블릿 (크롬 브라우저) |
| 운영 의지 | 4주간 실제 예약 등록 협조 가능한 매장 |

---

## 파일럿 기간

**총 4주** (준비 1주 + 운영 3주)

---

## 파일럿 진행 순서

### 1주차 — 세팅

| 순서 | 작업 | 담당 |
|------|------|------|
| ① | 매장 선정 및 동의 확인 | 뷰티링크 운영팀 |
| ② | 원장 계정 생성 (Firebase Auth) | 뷰티링크 운영팀 |
| ③ | 매장 기본 정보 입력 (`/settings`) | 원장 직접 |
| ④ | 디자이너 등록 및 근무시간·휴무 설정 (`/designers`) | 원장/매니저 |
| ⑤ | 시술 메뉴 등록 (`/services`) | 원장/매니저 |
| ⑥ | 네이버예약 매핑 설정 (`/integrations/naver`) | 원장/매니저 |
| ⑦ | 직원 계정 생성 및 권한 설정 (`/security`) | 원장 |
| ⑧ | 사용 방법 안내 (DEMO_SCRIPT.md 참고) | 뷰티링크 운영팀 |

### 2~4주차 — 실제 운영 테스트

| 주차 | 주요 활동 |
|------|---------|
| 2주차 | 예약 등록 시작, 캘린더 확인, 노쇼 관리 |
| 3주차 | 고객 CRM 이력 쌓기, 문자 템플릿 확인 |
| 4주차 | 전체 기능 복습, 불편사항 피드백 수집 |

### 종료 후

| 단계 | 내용 |
|------|------|
| 데이터 분석 | Firestore 기반 측정 지표 집계 |
| 설문 수집 | 원장·매니저·디자이너 각각 |
| 개선안 정리 | 피드백 → GitHub Issues 정리 |
| 제휴 협의 | 네이버 측과 파일럿 결과 공유 |

## 측정 지표

### 정량 지표 (Firestore 자동 집계)

| 지표 | 측정 방법 | 기준 |
|------|---------|------|
| 총 예약 등록 건수 | Firestore 예약 컬렉션 count | 4주 합산 |
| 네이버예약 외 예약 비율 | `source !== "naver"` 비율 | 목표: 30% 이상 전환 |
| 노쇼 건수 | `status === "noShow"` count | 이전 대비 감소 확인 |
| 취소 건수 | `status === "cancelled"` count | 이전 대비 변화 |
| 재방문 고객 수 | `visitHistory.length >= 2` 고객 수 | 방문 이력 누적 확인 |
| 고객 등록 수 | customers 컬렉션 count | |
| accessLog 생성 수 | 일별 액션 빈도 | 활성도 지표 |

### 정성 지표 (설문)

| 질문 | 응답 형식 |
|------|---------|
| 예약 등록 편의성 | 1~5점 |
| 캘린더 가독성 | 1~5점 |
| 고객 이력 관리 유용성 | 1~5점 |
| 네이버예약과의 병행 사용 편의성 | 1~5점 |
| 전반적인 만족도 | 1~5점 |
| 기존 방식 대비 개선된 점 | 주관식 |
| 불편하거나 부족한 점 | 주관식 |
| 실제 도입 의향 | 예/아니오/검토 중 |

## 파일럿 성공 기준

| 기준 | 목표 수치 |
|------|---------|
| 4주간 예약 등록률 | 기존 예약의 50% 이상을 뷰티링크로 등록 |
| 원장 만족도 | 평균 3.5점 이상 (5점 만점) |
| 노쇼 건수 | 이전 4주 대비 20% 이상 감소 |
| 재방문 고객 추적 | 재방문 고객 1명 이상 방문 이력 확인 |

## 파일럿 후 활용 방안

1. **네이버 제휴 협의 자료**: 파일럿 결과 데이터 + 매장 인터뷰 내용 첨부
2. **제품 개선**: 피드백 기반 UX 개선 → 다음 Phase 반영
3. **추가 파일럿 확장**: 성공 시 5~10개 매장으로 확대

---

## 파일럿 운영 시 주의사항

- 실제 고객 연락처는 외부 노출 금지 (마스킹 처리)
- Firebase Admin SDK 미사용 — 클라이언트 보안 원칙 준수
- 기존 네이버예약 운영에 영향 주지 않음 (병행 운영)
- 네이버예약 API 실제 호출 없음 (제휴 승인 전)
- 실제 문자/알림톡 발송 없음 (SMS API 계약 전)
