# 알려진 이슈 및 후순위 항목

> 즉각 수정이 필요하지 않은 이슈, 외부 의존 이슈, 나중에 개선할 사항 목록

## UI / UX

### 🟡 시술 메뉴 모달이 모바일에서 길다
- **현상**: 입력 항목(카테고리/이름/가격/소요시간/설명/담당 디자이너/네이버 메뉴명/사용여부)이 많아 모바일에서 스크롤이 김
- **현재 처리**: 바텀시트 + `max-h-[90dvh]` 내에서 스크롤 가능하게 처리
- **개선 여지**: 입력 항목을 스텝으로 나누거나 아코디언 UI 적용 가능
- **우선순위**: 낮음 (사용 빈도 낮음, 스크롤로 충분히 사용 가능)

### 🟡 캘린더 주간/월간 뷰 미구현
- **현상**: 일/주/월 버튼은 있으나 주간·월간 뷰 실제 그리드 미구현
- **현재 처리**: 버튼 클릭해도 동일한 일간 뷰 표시됨
- **개선 방향**: 주간은 7일 컬럼 그리드, 월간은 달력 형태
- **우선순위**: 중간

### 🟡 디자이너 휴무일 캘린더 편집 없음
- **현상**: `daysOff` 배열에 날짜 추가/삭제 UI 없음
- **현재 처리**: Firestore 직접 수정 또는 초기 데이터에 포함
- **개선 방향**: 디자이너 수정 모달에 달력 날짜 선택 UI 추가
- **우선순위**: 중간

## 기능 / 로직

### 🔴 실제 SMS/알림톡 API 미연동
- **현상**: 문자 발송 버튼은 있으나 실제 발송 없음 (Mock 상태)
- **이유**: 외부 API(SENS, 카카오 비즈니스) 계약 필요
- **개선 방향**: API Key 획득 후 서버 액션 또는 Firebase Functions로 연동
- **우선순위**: 외부 의존 (보류)

### 🔴 실제 네이버예약 API 미연동
- **현상**: 연동 준비 UI만 있고 실제 예약 동기화 없음
- **이유**: 네이버 공식 제휴 승인 필요
- **개선 방향**: API 승인 후 `/integrations/naver` 페이지 실제 연동
- **우선순위**: 외부 의존 (보류)

### 🟡 대시보드 차트 데이터가 Mock
- **현상**: 시간대별/출처 차트가 하드코딩된 Mock 데이터 사용
- **개선 방향**: Firestore 예약 데이터 집계 후 실시간 반영
- **우선순위**: 중간

### 🟡 캘린더 구독 날짜 고정 (DEMO_DATE)
- **현상**: 구독이 `2025-05-25` 고정 날짜만 사용
- **개선 방향**: `viewDate` 변경 시 해당 날짜로 구독 전환
- **참고**: 이미 `useEffect([salonId, viewDate])` 의존성 배열에 viewDate 포함되어 있어 코드 상으로는 작동함. 실제 Firestore 데이터가 있어야 확인 가능
- **우선순위**: Firestore 데이터 있을 때 검증 필요

## 테스트 / 검수

### 🟡 실제 로그인 테스트 미수행
- **현상**: 모든 테스트가 데모 모드(Firebase 미연결) 기준
- **필요**: 실제 Firebase 계정으로 로그인 후 기능별 스크린샷 검수
- **방법**: Vercel 배포 또는 로컬 `.env.local` 설정 후 테스트

### 🟡 ChatGPT 검수 범위 제한
- **현상**: ChatGPT는 실제 로그인이 불가능하여 코드/스크린샷 기준으로만 검수
- **해결**: Vercel 배포 후 공개 URL 공유, 스크린샷 첨부

### 🟡 모바일 실기기 테스트 미수행
- **현상**: Chrome DevTools 에뮬레이션만 확인, 실제 iPhone/Android 미확인
- **확인 필요**: safe-area-inset, 터치 타겟 크기, iOS Safari 스크롤 동작

## 보안

### 🟡 QA 검수센터 미구현
- **현상**: Firestore 연결 상태, 데이터 개수, 권한 체크를 한 화면에서 보는 /qa 페이지 없음
- **개선 방향**: owner 전용 진단 페이지 구현 예정
- **우선순위**: 중간

- **현상**: 고객 soft-delete 정책 미결정
- **개선 방향**: `isDeleted=true` 플래그 방식 검토
- **우선순위**: 낮음
