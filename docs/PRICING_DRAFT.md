## 추가 고려사항

### 가격 책정 기준

- 경쟁 서비스 대비 합리적 가격 (뷰티샵 전용 SaaS 평균 30,000~80,000원/월)
- 외부 API 비용(SMS, 알림톡)은 실제 발송 건당 별도 청구 또는 플랜에 포함 여부 결정 필요
- 네이버예약 API 연동 요금 구조는 네이버 제휴 조건에 따라 변동 가능

### 결제 구현 시 예상 사용 기술

- 토스페이먼츠 또는 포트원(아임포트) SDK
- Firebase Functions 또는 Next.js API Route
- 구독 상태 Firestore `salons/{salonId}/plan` 문서에 저장

### 무료 체험 정책 (안)

- 14일 Pro 무료 체험
- 신용카드 없이 시작 가능
- 이후 Free 또는 유료 플랜 선택
