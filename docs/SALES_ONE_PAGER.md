# 뷰티링크 — 영업용 기능 요약 (One Pager)

---

## 서비스 한 줄 소개

> **미용실·뷰티샵을 위한 예약·고객·디자이너 통합 관리 CRM**
> 네이버예약, 전화예약, 방문예약을 한 화면에서 관리하고, 고객 방문 이력과 노쇼를 체계적으로 관리합니다.

---

## 타깃 고객

| 타입 | 설명 |
|------|------|
| 1인 미용실 원장 | 모든 예약을 혼자 관리, 수기 메모 의존 |
| 3~10인 규모 뷰티샵 | 디자이너별 스케줄·예약 분리 관리 필요 |
| 네이버예약 활용 매장 | 네이버예약과 오프라인 예약 통합 필요 |
| 고객 관리 강화 원하는 매장 | 재방문율·노쇼 관리 개선 필요 |

---

## 해결하는 문제

1. **예약 분산**: 네이버·전화·방문 예약이 각각 따로 관리됨
2. **스케줄 충돌**: 디자이너 일정 모르고 중복 예약 발생
3. **고객 이력 소실**: 재방문 고객의 시술 이력·선호도를 기억 못함
4. **노쇼 관리 어려움**: 노쇼 고객 기록 없음, 리마인드 문자 수작업
5. **매출 파악 불가**: 일간/월간 매출을 즉시 파악하기 어려움

## 현재 구현 완료 범위 (Phase 1~16)

- Firebase Auth + Firestore 실연동
- 멀티테넌트 구조 (`salons/{salonId}` 격리)
- 16개 페이지 완전 구현 (TypeScript strict, 빌드 통과)
- Firestore 보안 규칙 역할별 완전 분리
- 모바일 반응형 (390px ~ 1920px)
- iOS Safe Area (dvh) 대응
