# 뷰티샵 전용 CRM '뷰티링크'의 네이버예약 연동 제휴 제안

> 작성일: 2026-06-09
> 문서 용도: 네이버예약 API 제휴 또는 협력 검토 제출용

---

## 한 줄 요약

> **네이버예약을 사용하는 미용실이 전화·방문·카카오 문의 예약까지 함께 관리할 수 있도록 돕는 보조 CRM입니다.**

---

## 문제 정의

현재 네이버예약을 사용하는 미용실은 다음과 같은 운영 불편함을 겪고 있습니다.

| # | 문제 |
|---|------|
| 1 | 네이버예약 외 전화·방문 예약은 메모장/엑셀 등으로 따로 관리됨 |
| 2 | 디자이너 휴무·근무일과 예약 관리가 분리되어 스케줄 충돌 발생 |
| 3 | 고객 방문 이력, 노쇼, 재방문 관리가 수기로 처리되어 이력 소실 |
| 4 | 시술 메뉴와 디자이너 매핑을 네이버와 내부 시스템에서 반복적으로 관리 |
| 5 | 소규모 미용실은 별도 CRM 도입이 어렵거나 비용·복잡성으로 포기 |

---

## 뷰티링크가 해결하는 것

| 기능 | 설명 |
|------|------|
| ① 예약 통합 관리 | 네이버예약 + 전화예약 + 방문예약을 동일 캘린더에서 관리 |
| ② 디자이너별 캘린더 | 일/주/월 3가지 뷰로 스케줄 파악, 휴무일 설정 |
| ③ 고객 CRM | 방문 이력, 시술 메모, 노쇼 횟수 자동 집계 |
| ④ 시술 메뉴 관리 | 카테고리·가격·소요시간 구조화, 비활성화 처리 |
| ⑤ 문자·알림톡 구조 | 리마인드·노쇼·취소 템플릿 준비 (실 발송은 API 계약 후) |
| ⑥ 네이버예약 매핑 준비 | 내부 디자이너·시술 메뉴 ↔ 네이버 명칭 1:1 매핑 사전 설정 |
| ⑦ 직원 권한 관리 | 원장·매니저·디자이너 역할 분리, 접근 로그 기록 |
| ⑧ 운영 대시보드 | 오늘 예약·신규 고객·매출·노쇼 통계 한눈에 파악 |

## 네이버 입장에서의 기대효과

| # | 기대효과 |
|---|---------|
| 1 | 네이버예약 사용 매장의 **운영 만족도 상승** — 예약 외 CRM 기능 보완 |
| 2 | **예약 데이터 품질 개선** — 디자이너/시술 정보 정합성 확보 |
| 3 | **노쇼·취소 관리 보조** — 리마인드 알림으로 예약 이행률 향상 |
| 4 | **미용실 업종 특화 연동 사례 확보** — 업종별 API 활용 레퍼런스 |
| 5 | **외부 보조 도구 생태계 확장** — 네이버예약 중심의 파트너 생태계 형성 |

## 파일럿 제안

### 대상
- 진주 지역 미용실 **1~3곳**
- 현재 네이버예약 사용 중인 매장
- 3~8인 규모 (디자이너 2명 이상)

### 기간
- **4주 운영 테스트**

### 파일럿 진행 순서

| 단계 | 내용 | 기간 |
|------|------|------|
| 1주차 | 매장 선정 → 계정 세팅 → 디자이너/시술 메뉴 등록 | 1주 |
| 2주차 | 네이버예약 매핑 설정 → 실제 운영 테스트 시작 | 1주 |
| 3~4주차 | 실제 운영 테스트 → 피드백 수집 | 2주 |
| 종료 후 | 측정 지표 분석 → 개선안 정리 → 제휴 협의 | - |

### 측정 지표

| 지표 | 측정 방법 |
|------|---------|
| 예약 등록 건수 | Firestore 예약 건수 집계 |
| 네이버예약 외 예약 비율 | 예약 경로 필드 집계 |
| 노쇼 건수 변화 | before/after 비교 |
| 취소 건수 변화 | before/after 비교 |
| 재방문 고객 수 | visitHistory 집계 |
| 직원 편의성 만족도 | 간단 설문 (1~5점) |
