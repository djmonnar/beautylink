# QA 체크리스트

> 실제 로그인 테스트는 사용자가 수행. ChatGPT는 스크린샷/코드 기준으로 검수.
> `[ ]` = 미확인 / `[x]` = 통과 / `[!]` = 이슈 있음

---

## 1. 인증 / 로그인

- [ ] 이메일/비밀번호 로그인 성공
- [ ] 잘못된 비밀번호 → 한국어 에러 메시지 표시
- [ ] 비로그인 상태에서 `/dashboard` 접근 → `/login` 리다이렉트
- [ ] 로그인 후 `/login` 접근 → 자동으로 `/dashboard` 이동
- [ ] 로그아웃 후 `/login`으로 이동
- [ ] Firebase 미설정 상태(데모 모드)에서 앱 정상 동작

## 2. 대시보드 (`/dashboard`)

### 기간 선택
- [ ] "오늘" 탭 — 오늘 날짜 기준 데이터 로드
- [ ] "최근 7일" 탭 — 7일 범위 데이터 로드

- [ ] 탭 전환 시 모든 차트·통계 갱신
- [ ] "새로고침" 버튼 동작

### 통계 카드
- [ ] 예약 건수 표시 (기간별 실집계)

### 차트
- [ ] 오늘 탭: 시간대별 예약 건수 막대차트 (08시~20시)
- [ ] 7일/30일 탭: 일별 예약 건수 막대차트
- [ ] 예약 출처 파이차트 (naver/phone/visit/kakao 실집계)
- [ ] 파이차트 범례: 출처명 + % + 건수 표시
- [ ] 차트 영역 가로 스크롤 없이 표시

### 예약 목록
- [ ] 오늘 탭: "오늘 예약 목록" 타이틀 + 시간순 표시
- [ ] 7일/30일 탭: "최근 예약 목록" 타이틀 + 날짜 컬럼 추가
- [ ] 데스크탑 테이블형 표시 (md 이상)
- [ ] 모바일 카드형 표시 (md 미만)
- [ ] 고객명·시술·디자이너·출처·상태 표시
- [ ] 예약 없을 때 "예약 데이터가 없습니다." 표시

### 디자이너별 예약
- [ ] 활성 디자이너 목록 표시 (inactive 제외)
- [ ] 예약 건수 + 진행바 표시 (최대값 상대 비율)
- [ ] 운영 요약 카드: 완료/대기/노쇼/취소 건수
- [ ] 오늘 탭: 가장 바쁜 시간대 표시

- [ ] `customers` — designer 쓰기 차단 확인
- [ ] `customerPrivate` — designer 읽기 차단 확인
- [ ] `reservations` — designer 타인 예약 읽기 차단 확인
- [ ] `accessLogs` — 생성만 가능, 수정·삭제 불가 확인
